## Requirements

* Node 18.16.1

## Installation

* clone this repo `git clone https://github.com/kevinyjiang/hc-apollo.git`
* navigate to the project `cd hc-apollo` 
* install dependencies `npm i`

## Environment Variables

Create a `.env` file in the project root with the following value(s):

`VITE_SOCKET_URL=ws://[YOUR_IP_ADDRESS]:4000/`

## Development

* launch dev server: `npm run dev`
* preview build: `npm run build && npm run preview`
